# 单格点海温分析

通过 DeepSeek Harness 的 `sst_analyze` 执行确定性分析，通过 `sst_set_style` 修改本 Skill 的默认图样式。当前工具只支持项目内的 A、B、missing-month 三组输入，不接受任意文件路径；不能声称已分析用户另行提供的数据。

默认演示样式：default

## 执行与验收

1. 将用户选择映射到 `case`：A 为首个格点，B 为第二格点，`missing-month` 为故意删去基准期月份的教学副本。未指定时用 A。没有指定基准期时使用 **1991–2020**；输出使用 `outputs/` 下不存在或为空的简单子目录名。
2. **实际调用 `sst_analyze` 才能声称完成数据检查。** 不用文件名、已有文字说明或模型推断代替验证。默认省略 `style`，工具会读取上面的默认样式行；用户只要求本次使用某种样式时才显式传入 `default` 或 `presentation`。

```json
{"case":"A","baseline_start":1991,"baseline_end":2020,"output":"demo-A-default"}
```

3. 根据真实工具返回判断成功。要求 `exitCode` 为 `0`、`report.status` 为 `ok`，并有本次科学产物。使用 `report.source`、`report.point`、`report.coverage`、`report.baseline`、`report.checks` 和 `report.spot_check` 说明来源、格点、覆盖期、参数与数值抽查。引用 `artifacts` 中本次图和摘要的路径，不声称已打开或逐行读取本工具未提供的文件。
4. **失败立即停止分析解释。** 根据返回的错误信息指出缺失月份或其他问题。输入校验失败时脚本返回退出码 `2`，错误报告为 `status: error`，不生成科学结果。不得自动删重、插值、补月、猜单位、缩短基准期或切换到正常数据；不得引用历史图作为本次结果。非空输出目录遭拒绝时，选择新目录重试；输入未修正时不要重复运行同一失败任务。

## 核心方法

- 输入为一个固定格点的预聚合月均 SST。脚本严格检查 CSV 与 metadata 的 SHA-256 配对、显式单位 `degree_Celsius`、格点一致、月份唯一且连续、自然月全部日期有效，以及连续完整的 30 年基准期。
- 每个历月的气候态是基准期内该历月 30 个完整月均值的算术平均；每月距平等于该月 SST 减去对应历月气候态。不能用所有月份的总平均替代同月气候态。
- 通过 `report.spot_check` 展示一个月份的 SST、同月气候态及两者之差；这是脚本返回的数值抽查，不应称为模型独立读取 CSV 后重算。
- 改基准期仅按用户明确请求执行，重新计算气候态与距平；SST 原值不应改变。一次只改基准期或图样式，便于解释差异。

## 修改与复用

修改默认图样式时调用：

```json
{"style":"presentation"}
```

此参数交给 `sst_set_style`；工具只修改本文件中独占行的枚举值，并返回修改前后值与文件校验值。随后重新加载同名 Skill，并在新的输出目录调用 `sst_analyze`，省略 `style` 以使用修改后的默认值。不要修改分析脚本或质量检查来完成样式调整。

`default` 与 `presentation` 按脚本设计只改变视觉样式。当前专用工具没有完成两次 CSV 的独立比较，因此不能宣称“已经逐值验证两次结果完全相同”；可如实报告两次参数与数值抽查，完整比较留给讲者在获准运行本地流程后完成。

新任务中加载本 Skill，用 `case: B` 复用相同方法；异常练习用 `case: missing-month`，提前说明这是人为删月的教学数据。无论说明如何，都必须实际调用验证工具，并以返回状态决定能否继续。

## 科学表述

- 结果只描述输入格点与时间段，不能把一个格点称为“南海平均”或泛化至整个海区。
- 正距平仅表示相对所选基准期同月气候态偏暖；本流程不进行显著趋势检验、因果归因或海洋热浪判定。
- 只引用返回来源中实际提供的产品名称、URL、检索时间等，不编造 DOI、论文、数据版本或处理步骤。区分 NOAA 分析产品与本演示的月均派生表。
- 从本次计算概括现象，研究者仍需确认方法和解释；不得宣称本流程完成了自主科学发现。
